THE DOORWAY: IITM SCHOOL CONNECT COURSE EXPLORER

Open index.html in Chrome, Edge, Firefox, or Safari. No server needed.

Includes all 20 courses from the provided Excel list, using the earlier student-friendly course guide.
Click any door to view its course. Each includes an eight-week roadmap, an activity, real-world inspiration, and links to the official page.

All course illustrations are local SVG images. The optional Google Fonts need internet; the site works without them.

Favorites and explored progress are stored only in your browser.

Age warnings: Introduction to Forensic Sciences II and From Statistics to Intelligence are for Classes XI-XII.

Real-world examples are broader field examples, not course outcomes. Verify costs, dates, rules and content with IIT Madras.
